# ⚡ CLive Backend (Node.js + Express + Socket.IO)

Real-time WebSocket and API server for the **CLive** chat application.

---

## 🚀 Tech Stack
- **Node.js**
- **Express.js** (HTTP Routing)
- **Socket.IO** (Real-time Messaging)
- **CORS** (Cross-Origin Resource Sharing)
- **Nodemon** (Dev Hot-Reloading)

---

## 📦 Setup & Commands

```bash
# Navigate to server folder
cd server

# Install dependencies
npm install express socket.io cors dotenv nodemon

# Start server
npm start
